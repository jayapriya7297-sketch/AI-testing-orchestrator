# REQ-010 Monthly total: questions for the requirement owner

Raised while generating tests on 2026-10-20. Status Planned: drafts are test.fixme.

1. **Which month.** Is "the current month" based on the user's local time, the server's,
   or UTC? The drafts use the test machine's local date.
2. **Filters.** Should the total follow the category filter (and the search, once REQ-009
   exists), or always cover the whole month?
3. **Whose expenses.** Only mine? Today the list shows every user's expenses (BUG-001);
   see also REQ-008 question 1 about the admin role.
4. **Format and zero.** Same format as amounts ("$1,234.50")? With no expenses this month,
   show "$0.00" or hide the total?
5. **Future dates.** Do expenses dated later in the current month count?
6. **Existing footer total.** The list footer already shows "expense-total", the sum of every
   listed expense (all months). Should it stay, become the monthly total, or sit beside it?
7. **UI details for the developer.** A data-testid for the monthly total is needed
   (e.g. "monthly-total").
