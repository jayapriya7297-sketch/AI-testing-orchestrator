# REQ-008 Data privacy: questions for the requirement owner

Raised while generating tests on 2026-10-20. Linked defect: BUG-001 (no ownership
check: every user can read, edit and delete every expense), fixed on 2026-10-28.

1. **Admin role.** Does "only my own expenses" apply to the admin too? The admin role
   and the "Created by" column suggest admin may be meant to see everyone's expenses.
   **Resolved (2026-10-28):** the admin is exempt for viewing only. Regular users read
   and write only their own expenses (404 otherwise). The admin can read all expenses
   (list, export, GET by id) but can edit and delete only their own; editing or
   deleting another user's expense returns 403 (the admin may know it exists).
2. **403 or 404.** For another user's expense, should the API answer 403 (exists, not
   yours) or 404 (doesn't reveal it exists)? **Resolved (2026-10-28)** by the answer to
   Q1: 404 for a regular user, 403 for the admin's edit or delete. Tests assert the
   exact status.
3. **Edit and delete in the UI.** Should the UI hide Edit and Delete for expenses that
   aren't yours? Still open, and now concrete: the admin's list shows other users'
   expenses with Edit and Delete buttons that fail with 403 (BUG-005). The API and DB
   tests cover "cannot edit or delete" for both roles.
4. **Import ownership.** Must imported rows always belong to the user who imports them?
   The requirement doesn't say.
