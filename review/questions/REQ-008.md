# REQ-008 Data privacy: questions for the requirement owner

Raised while generating tests on 2026-10-20. Linked defect: BUG-001 (no ownership
check: every user can read, edit and delete every expense).

1. **Admin role.** Does "only my own expenses" apply to the admin too? The admin role
   and the "Created by" column suggest admin may be meant to see everyone's expenses.
   No test covers the admin's view until this is answered.
2. **403 or 404.** For another user's expense, should the API answer 403 (exists, not
   yours) or 404 (doesn't reveal it exists)? Existing tests accept either.
3. **Edit and delete in the UI.** Should the UI hide Edit and Delete for expenses that
   aren't yours, or is that moot once other users' expenses are hidden from the list?
   No UI edit/delete test was drafted: under BUG-001 such a test would fail at "open
   edit" once the fix hides the row, and test.fail() would never report the fix.
   The API and DB tests cover "cannot edit or delete".
4. **Import ownership.** Must imported rows always belong to the user who imports them?
   The requirement doesn't say.
