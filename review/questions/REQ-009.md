# REQ-009 Search by title: questions for the requirement owner

Raised while generating tests on 2026-10-20. Status Planned: drafts are test.fixme.

1. **Match type.** Substring, prefix or whole word? The drafts type the full unique title,
   which works for all three.
2. **Whitespace.** Are leading and trailing spaces in the search text ignored?
3. **Empty-state text.** "No expenses found" (requirement) or "No expenses found."
   (the app's current empty state, with a period)? The draft accepts both.
4. **Category filter.** Does search combine with the category filter (AND), or reset it?
5. **Clearing.** Does clearing the search show the full list again?
6. **Export.** Should Export respect the current search, as it respects the category filter?
7. **Where it filters.** In the browser or through an API parameter? An API parameter
   would need API tests too.
8. **UI details for the developer.** A data-testid for the search input is needed
   (e.g. "search-input"). Should the list update as you type or on Enter?
