# Screenshots

Images for the main README. Add them here as PNG files with the names below, then add the
Screenshots section to the main README.

| File | What to capture |
|---|---|
| `github-actions-summary.png` | A GitHub Actions CI run page with the job summary (counts table from `reporting/job-summary.mts`) |
| `jenkins-build.png` | The `nightly-regression` job page: build history, test result trend and the "Playwright report" link |
| `jira-bug-from-n8n.png` | A Jira Bug created by n8n: `[Auto] <title>` with the labels `auto-test`, `nightly`, `at-<id>` (ideally with a "Failed again in build #N" comment) |
| `n8n-workflow.png` | The `test-failure-to-jira` workflow canvas in n8n |
| `excel-report.png` | The Summary sheet of `reports/results.xlsx` (counts, suite and product pass rate) |

Before capturing, check that no screenshot shows an email address, API token, webhook URL or Jira site
you don't want public.
